⏱ Пороги предупреждений
Пороги считаются до крайнего срока: чтобы не получить штраф, приёмку нужно завершить заранее, до конца таймера. В крайний срок придёт отдельное оповещение «завершите приёмку», после него принимайте излишками.

🌐 Прокси для Telegram
Если Telegram заблокирован. Применяется только для api.telegram.org.
Использовать проксиТолько для Telegram API
Логин/пароль — только для HTTP: Chrome не поддерживает SOCKS5 с авторизацией. MTProto-прокси не подходят. Пока прокси включён, системный прокси/VPN-расширение для остальных сайтов не действуют.

🕘 Рабочие часы
Вне рабочих часов оповещения не отправляются (чтобы ночью не будила забытая вкладка). Таймер и история продолжают работать. Если «до» раньше «с» — смена через полночь.
