# Безопасность

## Как сообщить об уязвимости
Не публикуйте подробности в открытых Issues. Воспользуйтесь
[приватным сообщением об уязвимости](https://github.com/EgorMIX/ozonturbopvztool/security/advisories/new)
(вкладка Security → «Report a vulnerability»). Опишите, что можно сделать, при каких условиях и как воспроизвести.

Никогда не присылайте свои токены (Telegram-бот, ntfy), пароли прокси и `access_token` сессии Ozon — ни в сообщениях,
ни в логах, ни в HTML со страниц. Если токен бота всё же попал в открытый доступ, отзовите его у
[@BotFather](https://t.me/BotFather) (`/revoke`).

## Поддерживаемые версии
Исправления выходят только для последней версии из [Releases](https://github.com/EgorMIX/ozonturbopvztool/releases).

## Модель угроз (кратко)
- Content-скрипты работают только на `https://turbo-pvz.ozon.ru/` и могут слать в service worker только данные
  таймера и перевозок (`TIMER_FOUND`, `TIMER_LOST`, `CARRIAGES_UPDATE`) и команды резервирования/подтверждения пакетов
  (`BAGS_RESERVE`, `BAGS_COMMIT`). Для пакетов проверяются путь страницы и вкладка-владелец резерва;
  остальные команды принимаются только со страниц расширения.
- Сайты не могут обращаться к расширению напрямую (`externally_connectable` не задан, открытых ресурсов нет).
- Данные страницы выводятся только через `textContent`; `eval` и внешний код не используются.
- Прокси применяется только к `api.telegram.org` (PAC-скрипт), поля прокси проверяются до подстановки.
- Секреты хранятся в `chrome.storage.local` открытым текстом — защитить их от того, у кого есть доступ к вашему
  профилю Chrome, расширение не может.
