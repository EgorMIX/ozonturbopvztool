## Что делает расширение

1. Находит таймер приёмки в DOM Ozon. Крайний срок — конец таймера минус finishMarginMin (по умолчанию 1 минута).
   Пороги 30/15/5 минут отсчитываются до крайнего срока; отдельное оповещение приходит в крайний срок.
   Расширение само не завершает приёмку — это делает сотрудник в Ozon.
2. Отправляет голосовые оповещения, push Chrome, Telegram и ntfy; есть пауза, отключение и рабочие часы.
3. Хранит историю приёмок, результаты и отправления по нескольким перевозкам, экспортирует CSV.
4. Автоматически нажимает «+» у пакетов M/L на экране выдачи; поддерживает выбор размеров, общие квоты вкладок и статистику.
5. Проверяет новые релизы на GitHub; позволяет экспортировать и импортировать настройки.

## Проверки и релиз

Node ≥18; npm install не требуется:

```bash
npm run check
npm run check:strict
npm test
npm run pack
```

После правок запускать check, для поведения — соответствующие регрессионные тесты; перед релизом — strict, test и pack.
Архив создаётся в dist/ozon-turbo-pvz-<версия>.zip. В него входит только extension/, manifest лежит в корне.

Для релиза версия manifest должна совпадать с разделом CHANGELOG и тегом v<версия>.
После проверок и объединения PR в main: GitHub → Actions → release → Run workflow (main).
Workflow создаёт тег, собирает ZIP и публикует GitHub Release. Проверить успешность workflow, наличие архива и его версию.
Релиз не считать опубликованным по одному локальному ZIP.

При новой проблеме уточнить версию, действия и ожидаемый результат; запросить минимальный обезличенный HTML нужного блока или ошибку.

## Оставшиеся ограничения

- Один активный таймер; несколько независимых ПВЗ одновременно не поддерживаются.
- Исчезновение таймера — наблюдение DOM, не подтверждение API Ozon. При закрытой/замороженной вкладке итог может быть «нет данных».
- При закрытом Chrome, сне компьютера и недоступной сети доставка не гарантируется; автоматических повторов отправки нет.
- Пропущенные старой версией данные, которые не сохранялись, автоматически восстановить нельзя.
- Квоты пакетов накопительные до ручного сброса. Счётчик подтверждает изменение поля, не физическую выдачу.
  DOM-клик и storage не являются одной транзакцией; незавершённый резерв истекает через 2 минуты.
- Прокси Chrome один: Telegram через указанный прокси, другие сайты DIRECT. SOCKS5 с логином и MTProto не поддерживаются.
- Бэкенд остаётся идеей; не начинать его разработку автоматически.
