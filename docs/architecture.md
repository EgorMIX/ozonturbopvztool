# Архитектура — 1.8.0

Chrome MV3, Chrome ≥108, без сборщика и внешних зависимостей.

| Компонент | Назначение |
|---|---|
| `settings.js` | Общие дефолты и проверка настроек; popup и `importScripts` в SW. |
| `background.js` | Таймер, история, уведомления, прокси, очередь команд, квоты пакетов. |
| `content.js` | Видимый таймер `/receiving…` и перевозки каждые 10 секунд, SPA-навигация. |
| `bags-content.js` | Клики на `/orders/session-new/<id>` и `/orders/session/<id>/…`. |
| `speech.js` | SpeechSynthesis на вкладке Ozon. |
| `popup.html`, `popup.js` | Таймер, история, пакеты, настройки, CSV, резервные копии и тесты. |

## Состояние

`ready` загружает storage до событий. `messageQueue` сериализует команды и алармы, `historyQueue` — изменения истории,
`alarmQueue` с номером поколения — очистку и создание расписания. Ответ команды ждёт её историю и расписание.
Listener возвращает `true` для асинхронного ответа; неизвестная команда получает `unknown_message`.

Запуск восстанавливает расписание, паузу, ожидание пропавшего таймера и запись старой активной сессии.
Настройки проходят `PVZSettings.normalize`: импорт проверяется строго до записи; старые повреждённые значения
заменяются дефолтами. `pvzSettings` пишет только SW, popup отправляет патч раздела.

## Приёмка

`endsAt` — конец таймера, `endsAt − finishMarginMin` — крайний срок. Чтения в пределах ±90 секунд относятся
к одной сессии. Изменение времени переносит алармы без сброса `firedFor` и `deadlineNotified`.
`tabId` защищает живую сессию вкладки-источника от подмены другой вкладкой.

Исчезновение DOM-таймера — `TIMER_LOST`, `lostAt` и 2 минуты ожидания; возвращение той же сессии отменяет ожидание.
`reason: navigation` не завершает приёмку: пользователь мог перейти к выдаче во время приёмки. Без наблюдённого
завершения результат может быть `unknown`.

Новые перевозки привязываются по статусу «Приёмка». Уже связанные принимают финальные числа и с другим статусом.
Обновляется текущая история, после завершения — последняя связанная запись в пределах 2 часов.
Виджет перевозок и скрытые узлы исключены из поиска таймера. Фикстура двух перевозок —
`fixtures/receiving-two-carriages.html` (178 из 541).

История — максимум 300 записей; popup показывает 50 и сводку за 30 дней без debug-сессий.
`storage.onChanged` обновляет открытый экран. Очистка сохраняет текущую приёмку. Изменение запаса обновляет
крайний срок активной записи; завершённые записи не пересчитываются.

## Авто-пакеты

Подпись — `paragraph-large`, текст «Пакет M • доступно N», контейнер — прямой родитель подписи.
Серия одна; перед кликом проверяются URL, соединение DOM, режим, размер и кнопка.

1. `BAGS_RESERVE {label}`: SW проверяет общую квоту, включая резервы других вкладок, и сохраняет UUID,
   размер, `tabId`, срок 2 минуты до ответа.
2. Content-скрипт кликает и до секунды ждёт увеличения количества.
3. `BAGS_COMMIT {token, added}` снимает резерв и увеличивает счётчик при `added: true`.
   Повторный commit не считается дважды; неподтверждённый клик не увеличивает статистику.

Резервы переживают рестарт SW. Квоты накопительные до `BAGS_RESET`; глобальное отключение блокирует пакеты,
пауза глушит только оповещения. Смена URL, размера или отключение прекращает серию.

## Сообщения и безопасность

Content может отправлять только `CONTENT_MSG_TYPES`: `TIMER_FOUND`, `TIMER_LOST`, `CARRIAGES_UPDATE`,
`BAGS_RESERVE`, `BAGS_COMMIT`. Команды пакетов проверяют путь и владельца резерва.
`isAllowedSender` требует ID своего расширения и HTTPS URL Ozon; остальные команды — только страницам расширения.
Popup использует `SETTINGS_UPDATED`, `GET_STATE`, `GET_LOG`, `SET_MODE`, `TIMER_MANUAL`, `TIMER_CLEAR`,
`BAGS_RESET`, `HISTORY_CLEAR`, `CHECK_UPDATE`, `DEBUG_*`. SW отправляет вкладке `SPEAK`; popup — `GET_PAGE_INFO`.

## Storage и алармы

| Ключ storage.local | Содержимое |
|---|---|
| `pvzSettings` | Общая схема `settings.js`, включая секреты каналов и прокси. |
| `timerState` | Время, `startedAt`, `updatedAt`, `endsAt`, `lostAt`, `tabId`, `sessionId`, источник, запас, пороги, перевозки. |
| `acceptanceHistory` | Начало, крайний срок, результат, завершение, перевозки и отправления. |
| `modeState` | active / paused / disabled и конец паузы. |
| `carriagesState` | Последние перевозки, время чтения, вкладка. |
| `bagsSessionStats`, `bagsReservations` | Счётчики и незавершённые резервы. |
| `updateInfo` | Последняя проверка версии GitHub. |

Разовые алармы: `threshold_*`, `deadline_reached`, `timer_lost_grace`, `pause_end`.
Периодические: `badge_tick` — 1 минута, `update_check` — сутки. Popup обновляется каждую секунду;
период бейджа не задаёт точность разовых порогов.

Telegram/ntfy: таймаут 15 с, тесты не меняют рабочие настройки. ntfy — UTF-8 JSON, HTTPS, Bearer-токен.
Свой сервер получает optional permission конкретного origin; `https://*/*` только объявляет необязательную
возможность, не выдаёт доступ ко всем сайтам при установке. Прокси — PAC для Telegram, HTTP-логин через
`onAuthRequired`; ограничения перечислены в `known-issues.md`.

## Проверки

`npm run check:strict`, `npm test`, `npm run pack`. CI и релиз запускают регрессионные тесты.
Браузерные проверки с HTML-фикстурами находятся вне репозитория; Playwright не является зависимостью проекта.
