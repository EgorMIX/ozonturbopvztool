# Публикация в Chrome Web Store — тексты и обоснования

Черновик для заполнения карточки в [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
Архив для загрузки — `dist/ozon-turbo-pvz-<версия>.zip` (`npm run pack` или артефакт релиза на GitHub).

## Риски перед подачей (решает владелец)
- **Название с чужим брендом.** Правила магазина запрещают вводить в заблуждение о связи с другой компанией. «Ozon» в
  названии и иконке могут счесть выдачей себя за Ozon. Безопаснее назвать, например, «Таймер приёмки для Turbo-PVZ
  (неофициальный)» и не использовать логотип Ozon. В описании обязательно оставить пометку «неофициальное».
- **Единое назначение (single purpose).** В расширении два модуля — таймер и авто-пакеты. Подавать как одно назначение:
  «помощник сотрудника ПВЗ в веб-интерфейсе Turbo-PVZ». Если ревью не примет — вынести авто-пакеты в отдельное
  расширение.
- **Автоматизация чужого интерфейса.** Авто-пакеты нажимают кнопки на сайте Ozon. Проверьте, что это не нарушает
  правила работы с Turbo-PVZ для вашего пункта.
- **Модуль прокси** (`proxy`, `webRequest`, `webRequestAuthProvider`) удлиняет ревью и пугает предупреждениями при
  установке. Если в магазине он не нужен (Telegram доступен или есть ntfy) — можно собрать вариант без него.

## Карточка
**Название (до 75 символов):** Ozon Turbo-PVZ Timer _(см. риск про бренд выше)_

**Краткое описание (до 132 символов)** — совпадает с `description` в `manifest.json`:
> Неофициальный помощник для Turbo-PVZ: оповещения до конца приёмки (голос, push, Telegram, ntfy) и авто-пакеты.

**Подробное описание:**
> Неофициальное расширение для сотрудников пунктов выдачи, работающих в веб-интерфейсе turbo-pvz.ozon.ru. Не связано с
> Ozon.
>
> Таймер приёмки: расширение находит на странице приёмки обратный отсчёт и заранее предупреждает, что время
> заканчивается, — по умолчанию за 30, 15 и 5 минут. Пороги и тексты настраиваются. Каналы: голос, push-уведомление
> Chrome, Telegram (через вашего бота) и ntfy (приложение на телефоне). Есть ручной таймер, пауза и отключение.
>
> Авто-пакеты: на экране выдачи расширение само нажимает «+» у пакетов M и L до доступного количества. Можно выбрать
> размеры и задать лимиты; ведётся статистика.
>
> Приватность: расширение работает только на turbo-pvz.ozon.ru, не собирает аналитику и отправляет данные только в
> включённые вами каналы (Telegram, ntfy). Исходный код открыт: https://github.com/EgorMIX/ozonturbopvztool

## Вкладка «Конфиденциальность» (Privacy practices)
**Единое назначение:**
> Помогает сотруднику пункта выдачи в веб-интерфейсе Turbo-PVZ: предупреждает о скором окончании таймера приёмки и
> автоматически заполняет количество пакетов на экране выдачи.

**Обоснования прав:**
| Право | Обоснование |
|---|---|
| `notifications` | Показывает push-уведомление о приближении конца приёмки. |
| `alarms` | Срабатывание порогов оповещения в нужное время, даже когда вкладка заморожена браузером. |
| `storage` | Хранит настройки пользователя, состояние таймера и статистику пакетов локально. |
| `scripting` | Запасной способ озвучить оповещение на вкладке turbo-pvz.ozon.ru, если content-скрипт не ответил. |
| `proxy` | По желанию пользователя направляет запросы к api.telegram.org через указанный им прокси (PAC только для этого хоста), если Telegram недоступен в его сети. |
| `webRequest`, `webRequestAuthProvider` | Передать логин и пароль HTTP-прокси, указанного пользователем, при запросе авторизации от этого прокси. |
| host `turbo-pvz.ozon.ru` | Читает таймер приёмки и количество пакетов, нажимает «+» у пакетов, озвучивает оповещения на этой вкладке. |
| host `api.telegram.org` | Отправляет оповещение в Telegram-чат пользователя через его бота. |
| host `ntfy.sh` | Отправляет оповещение в топик ntfy пользователя. |

**Удалённый код:** не используется (весь код в пакете).

**Сбор данных** — отметить:
- «Authentication information» — да: токен бота Telegram, токен ntfy, логин/пароль прокси вводит пользователь; хранятся
  локально, используются только для отправки его оповещений.
- «Website content» — да: время таймера и количество пакетов со страницы turbo-pvz.ozon.ru, обрабатываются локально.
- Остальные категории — нет.

Подтверждения: данные не продаются третьим лицам; не используются для целей, не связанных с единым назначением; не
используются для оценки кредитоспособности.
