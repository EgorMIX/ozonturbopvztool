# Скриншоты интерфейса

Сняты в Chromium с настоящими `popup.html`, `settings.js` и `popup.js` версии 1.8.0.
Chrome API подменён для демонстрации сохранённых настроек, таймера и истории без доступа к рабочему Ozon.
Оформление и элементы интерфейса не изменялись. Часовой пояс примера — Москва.

- `timer.png` — верх вкладки таймера до конца настроек порогов.
- `history.png` — история с активной, своевременной и опоздавшей приёмкой; номера перевозок вымышлены.
- `bags.png` — выбор размеров, квоты и счётчики пакетов.
- `ntfy.png` — раздел ntfy с примером топика, без токена и без отправки уведомлений.

Все данные демонстрационные, секретов и клиентских данных нет. Скрипт съёмки хранится вне репозитория;
Playwright не добавлен в зависимости расширения.
